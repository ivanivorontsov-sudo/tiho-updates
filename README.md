# tiho-updates

Публичный канал подписанных обновлений для браузера **Тихо** (`org.ivanivorontsov.tiho`, WebView-версия, начиная с 1.1.0).
Здесь лежат только данные. Исходники браузера хранятся в отдельном приватном репозитории.

| Путь | Что это |
|---|---|
| `content/manifest.json` + `.minisig` | Манифест пакета содержимого: версия, срок действия, `min_app_version`, `min_webview_major`, SHA-256 и размер каждого файла |
| `content/packs/<N>/…` | Файлы пакета N: списки фильтров (`filters/`), фишинг/malware-списки (`security/`), JS-шимы защиты (`js/`), `payment-domains.json`, каталог userscripts |
| `app/update.json` + `.minisig` | Описание обновления APK: versionCode, SHA-256, размер, срок действия, SHA-256 сертификата подписи APK |
| `userscripts/` | Userscripts из каталога. Их SHA-256 закреплены в `catalog.json` внутри подписанного пакета |
| `keys/*.pub` | Публичные ключи подписи обновлений в формате minisign (Ed25519) |

## Как приложение проверяет обновления

1. Скачивает `manifest.json` и `manifest.json.minisig`. Используется только HTTPS (`raw.githubusercontent.com`).
2. Проверяет подпись Ed25519 одним из двух ключей, вшитых в приложение: основным или резервным. Ключ подписи APK для этого **не** используется.
   Подписанный комментарий (trusted comment) должен называть ту же версию пакета.
3. Пакет отклоняется, если:
   - версия не больше уже принятой (это защищает от отката и повтора);
   - срок действия истёк;
   - приложение старше, чем `min_app_version`.
4. Каждый файл скачивается во временный каталог и сверяется с размером и SHA-256 из манифеста.
   Затем пакет атомарно подменяет текущий. Предыдущая версия сохраняется.
5. Если с новыми списками блокировщик не собирается, приложение автоматически возвращает предыдущую версию.
6. Список платёжных доменов только дополняется: обновление не может убрать встроенные или ранее известные домены.
   Минимальную версию WebView обновление может только поднять.
7. Обновление APK устанавливается только после подтверждения пользователем. Приложение проверяет:
   - подпись `update.json`;
   - SHA-256 скачанного APK;
   - имя пакета и versionCode;
   - сертификат подписи APK. Он должен совпадать с вшитым: `F1:72:85:19:60:CF:08:63:34:B7:14:91:FB:DC:48:89:86:1E:1E:EB:60:7E:4F:2D:40:6C:BD:86:FF:90:D6:D0`.

## Источники списков

Списки фильтров берутся из своих первоисточников и распространяются на их условиях:
- EasyList / EasyPrivacy / RU AdList / Fanboy;
- uBlock Origin uAssets;
- AdGuard;
- Peter Lowe;
- HaGeZi;
- malware-filter: phishing-filter, URLhaus.

`payment-unbreak.txt` — это исключения Тихо для антифрод- и 3-D Secure-скриптов на страницах оплаты.
